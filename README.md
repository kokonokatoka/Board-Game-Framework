## ✨ 主な機能・特徴

- **パスワード・合言葉不要！クリック一発合流**:
  - ゲームをクリックするだけで、1人目なら待機（一人練習中）、2人目以降なら自動で合流して対戦がスタート！
- **完全ゼロサーバー (WebRTC P2P)**:
  - PeerJSを利用し、プレイヤー間で直接P2P通信。サーバー費用・維持管理ゼロ。
- **URL共有で一発合流**:
  - 画面上部の「📋 招待リンク」を送るだけで、友達が開いた瞬間に同じ部屋に対戦合流。
- **モジュール型プラグイン設計**:
  - `games/*.js` に `window.BoardArena.registerGame({ ... })` を定義し、`index.html` に読み込ませるだけでポータルカタログに自動登録されます。

## 🤝 開発参加ガイド（初心者向けPR手順）

「新しいゲームを追加したい！」「コードネームに面白い単語を追加したい！」「デザインを良くしたい！」という方は、以下の手順で気軽にプルリクエスト（PR）を送ってください！

### 🚀 方法①：ブラウザだけで完結！（ソフトのインストール不要・3分）
*単語の追加やちょっとした修正なら、ブラウザの画面上だけでPRを送ることができます。*

1. 画面右上の **「Fork」** ボタン（フォークのマーク）を押し、自分のアカウントにコピーを作成します。
2. 変更したいファイルを開きます（例: コードネームの単語追加なら `games/codenames.js`）。
3. 右上の **鉛筆アイコン（Edit this file）** を押して編集します。
4. 編集後、右上の緑の **「Commit changes...」** を押し、**「Create a new branch for this commit and start a pull request」** にチェックを入れて **「Propose changes」** ➔ **「Create pull request」** を押せば完了です！

### 💻 方法②：自分のPCで動かしながら本格開発！（新ゲームの追加など）
*自作のボードゲームを追加したい場合は、無料ツール「GitHub Desktop」を使うとマウス操作だけで簡単にできます。*

1. **[GitHub Desktop](https://desktop.github.com/)** をインストールしてログインします。
2. 本リポジトリをForkし、GitHub DesktopでClone（ダウンロード）します。
3. 新しいブランチを作成します（例: `feature/my-game`）。
4. `index.html` をダブルクリックするだけで、ローカル環境ですぐに動きます。
5. `games/` フォルダ内に新しいゲームの `.js` を作り、`index.html` に `<script src="games/mygame.js"></script>` を追加します。
6. GitHub Desktopで変更をコミット＆プッシュし、**「Create Pull Request」** を押してPRを送信します！
